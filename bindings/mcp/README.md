# MCP binding

`bops serve-mcp` is an MCP server on stdio: one tool per `bops` command that has an `mcp` surface in `bops/commands.json`. `tools.json` is the list it serves by default, generated by `bops gen mcp`; don't edit it here. CI fails if it and the generator disagree.

beads' own guidance is the CLI and hooks first, because tool schemas cost tokens on every turn. Prefer the [Claude Code binding](../claude-code/)'s skill where a harness can run shell commands; use this where it can only call tools.

| | |
|---|---|
| Tools | Read-only by default: `next`, `sweep`, `stale`, `status`, `reap`, `gc`, `lint`, `doctor`, `gates`, `deps`, `version`. `sweep`, `reap` and `gc` are their previews (`readOnlyHint` true; they may ask the forge, as `--forge` says), with or without `--enable-writes`: `dry-run: false` is refused, because closing beads, releasing another run's claim or deleting a claim ref is a person's decision, made at the CLI ([PROCESS §12](../../docs/PROCESS.md#12-recovery-runbook-bops-ledgers)). `--enable-writes` adds `claim`, `note`, `renew`, `release` and `land` (`bops gen mcp --enable-writes` prints that list); `claim` takes no `force` and refuses `force: true`, since a takeover is a person's too. `sync` and `session-start` are not tools. |
| A call | Runs `bops <command> ... --json` with the same binary, in the server's working directory, and returns its JSON document, compacted. Exit 3 (a negative verdict, `ok:false`) is a result; exit 1 or 2 is a tool error. Text (`note`, `release`) goes on stdin. |
| Pagination | A result over 20 kB comes back 20 kB at a time, with a cursor; call the same tool with `{"cursor": "..."}` for the next page. The server keeps the last 32 paginated results. |
| Protocol | JSON-RPC 2.0, one message per line; MCP revisions 2025-06-18, 2025-03-26 and 2024-11-05; the tools capability only. Standard library, no SDK. |

## Install

```bash
go install ./cmd/bops                                    # from bops/ in a beads-ops checkout
claude mcp add bops -- bops serve-mcp                    # Claude Code, read-only tools
claude mcp add bops -- bops serve-mcp --enable-writes    # with the write tools
```

The run identity that holds a claim is the working directory's (SPEC §3), so start the server in the worktree where the agent works.
